Getting Started

Developer Mode Installation

Lycoris is loaded as an unpacked browser extension. Follow these instructions to download, unpack, and load the extension into your browser.

Latest Release

Contains all compiled assets, local background removal modules, and manifest v3 configurations.

Installation Steps

01

Download and Extract

Download the extension archive using the button above. Extract the downloaded lycoris-extension.zip file to a folder on your computer. Keep this folder in a permanent location (deleting or moving it will unload the extension).

02

Choose Your Browser

Select your browser below to see customized instructions on how to load the unpacked folder.

  1. Open Chrome and navigate to chrome://extensions
  2. Toggle the Developer mode switch in the top-right corner.
  3. Click the Load unpacked button in the top-left corner.
  4. Select the extracted folder containing the manifest.json file.
  1. Open Microsoft Edge and navigate to edge://extensions
  2. Enable the Developer mode toggle switch at the bottom of the left sidebar.
  3. Click the Load unpacked button at the top of the page.
  4. Choose the extracted folder containing the manifest.json file.
  1. Open Brave Browser and navigate to brave://extensions
  2. Switch on the Developer mode toggle in the top-right toolbar.
  3. Click the Load unpacked button on the top menu.
  4. Browse and select the extracted folder directory.
  1. Open Firefox and navigate to about:debugging#/runtime/this-firefox
  2. Click the Load Temporary Add-on... button.
  3. Navigate into the extracted folder and select the manifest.json file to load.
  1. Open Safari, open Settings > Advanced, and enable Show features for web developers.
  2. Choose Show Extension Builder from the Developer menu.
  3. Since Safari requires native App packaging, use Xcode's converter tool in the Terminal: 
    xcrun safari-web-extension-converter /path/to/extracted-folder
